### 5. 리뷰 짝 (5분)

1인당 리뷰 2개를 채우기 위해 순환 방식 제안 (4명: A, B, C, D)

| 차례 | 리뷰 방향 |
| --- | --- |
| 첫 번째 PR | A → B → C → D → A (각자 다음 사람 PR 리뷰) |
| 두 번째 PR | A → C, B → D, C → A, D → B (건너편 사람 PR 리뷰) |

이렇게 하면 모두 리뷰 2개를 서로 다른 사람에게 쓰게 됩니다.
